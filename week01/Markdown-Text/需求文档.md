# 需求文档：Python脚本----Markdown 目录生成器

## 一、目的

把 Markdown 文件里的标题提取出来，生成一个目录文件 toc.md，方便快速查看文档结构。

## 二、输入

- 一个或多个 Markdown 文件（扩展名为 .md 或 .markdown），通过命令行参数传入。
- 示例：python md_toc_min.py 需求文档.md README.md

## 三、处理逻辑

1. 逐个读取传入的 Markdown 文件。
2. 找出所有标题行（以 1~6 个 # 开头）。
3. 按标题级别生成缩进列表：一级标题不缩进，每多一级多缩进 4 个空格。

## 四、输出

- 在运行命令的当前目录生成 toc.md。

## 五、异常处理

- 文件不存在、不是文件、或不是 Markdown 文件：跳过该文件并提示，程序不崩溃。
- 文件读取失败：提示错误，继续处理其他文件。
- 文件里没有标题：该文件下不输出列表项，不报错。

## 六、验收标准

给定多个测试文件 test.md，运行 python md_toc_min.py test.md 后，生成的 toc.md 。
